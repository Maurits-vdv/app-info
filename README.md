# Notitiehulp — openbare appinformatie

Deze repository bevat uitsluitend de statische informatiewebsite en privacyverklaring
voor de persoonlijke OAuth-app **Notitiehulp**.

- `index.html`: uitleg over de app en het gebruik van Google Calendar.
- `privacy.html`: gegevensgebruik, betrokken diensten en intrekken van toestemming.
- `gebruik.html`: afbakening tot persoonlijk gebruik.
- `style.css`: lokale vormgeving; geen scripts, tracking of externe fonts.

De eigenlijke agentcode, configuratie, agenda, notities en credentials horen niet in
deze openbare repository. GitHub Pages publiceert de root van `main`.

Privacyvragen of technische opmerkingen kunnen via Issues, zonder persoonlijke
gegevens, afspraken of toegangscodes te delen.
